# DSA01 Assignment 2 (CO2) - Source Files and Outputs

Seven C++17 source files are organized into Task01 through Task07.
Each task folder contains its `.cpp` file, actual program output text, and a terminal-style PNG screenshot.
Task02 also includes compiler warning evidence when emitted by GCC.

## Compile
g++ -std=c++17 -Wall -Wextra filename.cpp -o output

## Run on Windows
.\output.exe

## Important
The screenshots were generated from the programs executed in this environment.
Re-run the programs on your own computer and capture your own VS Code screenshots for submission.
Q6 benchmark timing and Q7 comparative performance measurements must be measured on your own machine.
